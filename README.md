# CCM HPC GPU demonstration

This repository contains all the code and the enviromental setup requrired to replicate the results of the CCM 
"Accelerating research with gpus on high perfomance computing clusters" lecture. 

To replicate the results you will need to set up several conda environments because they have confliciting dependenices. 
The code in the "live demo" was done in the correspoding conda environments decribed in the "environment" folder. There
are couple of reduncincies within the enviroments because of trial and error. All the code that uses the respeictive 
environments is in the "ccm_demo" folder.

If you have any questions or issues please crate an issues in this repository.
